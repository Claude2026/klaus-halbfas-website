SOUNDING 01

Five bearings

Operations software fails in one of two ways: it panics, or it hides. Waterline is built to do neither. Every rule in this document descends from five bearings — fixed points the system never argues with.

B–1

The waterline

Every screen has one horizontal datum. Above it: the calm summary — what the operation is doing right now, readable in three seconds. Below it: the working depth — dense tables, detail, action. Never more than one waterline per screen.

B–2

Color is state

The chrome is colorless chart-paper. Beacon magenta marks what you can act on; buoyage colors mark how things are going. There is no decorative color anywhere. When something turns red, it is the only red thing you see.

B–3

Contours, not shadows

Depth is drawn the way charts draw it: hairlines and tonal steps. No blur, no glass, no glow. Only layers that truly float — menus, dialogs, hails — cast a shadow, and it is the only shadow in the system.

B–4

Numbers are the interface

An operations tool is read like an instrument. Every figure is set in the data face with tabular numerals, right-aligned, same precision down a column. A number you can't compare to its neighbor is a number wasted.

B–5

One motion

A single easing curve, three durations, and a purpose test: motion exists to show causality — this opened that, this moved there. Nothing loops, nothing pulses for attention, nothing moves to decorate.

SOUNDING 02

Color: chart paper & signal

On a real nautical chart, magenta is reserved by international convention for what humans added to the water — lights, routes, cautions, things a navigator acts on. Waterline adopts the convention whole: the ground is paper, the accent is Beacon, and status speaks buoyage.

Chrome earns no color. An element is magenta because you can act on it, or buoyage because it reports a condition — never because it wanted to look important.

Waterline doctrine · after chart convention INT1

Daywatch — the working theme

Buoyage — the status system

Four conditions, named for the marks that keep ships off the rocks. Each pairs a text-safe ink with a wash for fills, and each carries a distinct tick shape — circle, diamond, square — so state survives color-blindness and grayscale printing.

Nightwatch — the dark theme

Ship bridges run dimmed displays at night to protect the crew's night vision. Nightwatch follows: not an inversion but a re-mix — bone ink on deep water, contours barely brighter than the ground, Beacon lifted so it keeps its signal value. Try the theme switch in the masthead; both themes are first-class.

Rules of engagement

Do

Reserve Beacon for interaction. One primary action per waterline region. When a screen is healthy, it should be almost entirely paper and ink.

Don't

Use buoyage colors for branding, charts-by-default, or emphasis. Never place two solid Beacon buttons side by side. Never introduce a hue outside this page.

SOUNDING 03

Typography: two voices

Waterline speaks in two voices. Schibsted Grotesk is the human voice — labels, prose, headings; confident, slightly warm, unmistakably not another neo-grotesque default. Spline Sans Mono is the instrument voice — every number, ID, timestamp, and annotation, the way figures sit printed on a chart margin.

Setting rules

Do

Set every number in the data face with tabular-nums. Right-align numeric columns. Keep prose near 65 characters. Uppercase only the annotation voice, always letter-spaced.

Don't

Mix voices in one figure ("1,204" in the UI face next to "u/h" in mono). Bold entire rows for emphasis — hoist a pennant instead. Use italics anywhere in the product.

SOUNDING 04

Space: the fathom grid

One fathom = 8px. All spacing is whole fathoms, with a half-fathom (4px) reserved for the inside of dense components. The result is a rhythm you can feel down a whole page — and the waterline layout that gives KEEL its shape.

The waterline layout

The anatomy of every KEEL screen. Above the waterline, gauges answer "how are we doing?" — sparse, large figures, generous air. Below it, the ledger answers "what needs me?" — dense, keyboard-first, built for hours of work. The datum itself is a drawn rule, labeled, always in the same place.

SOUNDING 05

Depth: contours, not glass

The last decade of interface fashion rendered depth as material — glass, frost, blur, glow. Waterline goes the other way, back to the chart table: depth is drawn. A surface is higher because a hairline bounds it and its tone steps half a shade off the paper. It's calmer, it's faster to render, and it never fights the data for attention.

Level 0 — Paper

The chart itself. Content sits directly on it.

Level 1 — Plate

Hairline + half-step tone. All panels, cards, gauges.

Level 2 — Cast

The only shadow in the system — menus, dialogs, hails. If it doesn't float over content, it doesn't cast.

SOUNDING 06

Motion: the wake

One easing — cubic-bezier(0.22, 0.61, 0.21, 1) — a firm start that settles like water closing behind a hull. Three durations, and nothing else. Press play; each puck runs the same curve.

Do

Animate to show causality: a drawer follows its trigger; a removed row collapses so the eye keeps its place. Honor prefers-reduced-motion completely.

Don't

Pulse, bounce, shimmer, or loop. A critical state is announced by a pennant and a hail — never by blinking. Nothing in Waterline moves while you are reading.

SOUNDING 08

Patterns

How the parts assemble into KEEL itself. The full working assembly is the KEEL Console demo — these are the standing orders it follows.

Three-second rule

Anyone walking past a screen learns the operation's condition in three seconds, from the gauges alone. If a gauge needs explanation, it measures the wrong thing.

Exceptions first

Ledgers sort trouble to the top by default: Port, then Quarantine, then Fog, then Starboard. A healthy operation reads as a quiet page — and that quiet is information.

Detail slides, never navigates

Selecting a row opens a detail pane below the waterline; the ledger keeps its scroll and selection. Full-page navigation is reserved for changing section, not inspecting a record.

Empty states give a heading

An empty ledger names the fact and the next action: "No unscheduled orders. Intake closes at 16:00." — never an illustration, never an apology.

SOUNDING 09

Voice: the logbook

KEEL writes like a good watch log: fact, consequence, action. Short declaratives, present tense, numbers over adjectives, zero exclamation marks. The interface is an instrument; instruments don't emote.

Do

Name the fact, then the handled consequence.

Line 4 stopped. Spindle overtemp at 06:41. Incident opened and assigned to M. Okafor.
Batch split. 12,800 units → Line 3 (8,000) and Line 1 (4,800). Due dates unchanged.
Don't

Apologize, decorate, or bury the number.
